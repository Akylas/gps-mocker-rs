## Default Permission

Allows the app to inspect mock-provider status, open the developer settings
screen, and drive Android's test location providers.

#### This default permission set includes the following:

- `allow-check-status`
- `allow-open-developer-settings`
- `allow-start-mocking`
- `allow-stop-mocking`
- `allow-push-location`
- `allow-set-route`
- `allow-set-playback`
- `allow-set-notification-mode`
- `allow-set-system-bars`
- `allow-registerListener`
